# Security policy

Arbalete is a web browser: it handles untrusted content and users' private data. Security issues are taken
seriously.

## Reporting a vulnerability

Do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/amenophis/arbalete/security/advisories/new).

Include the affected version or commit, the steps to reproduce and the impact you observed.

## Supported versions

Only the latest release receives security fixes.
